## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/nitu/Computer_Vision_Day_1.git
```

Move into the project directory:

```bash
cd Computer_Vision_Day_1
```

Install the required libraries:

```bash
pip install opencv-python numpy
```

---

## ▶️ How to Run

Run any program using:

```bash
python Q01_read_display.py
```

You can replace the filename with any other question file, for example:

```bash
python Q15_resize.py
```
